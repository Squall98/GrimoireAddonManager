# ⌨️ Commands

`/gam`, `/maa` and `/mesaddons` all work the same (you can change them in the options). Words in French work too: `/gam aide` = `/gam help`.

39 sub-commands, generated from the add-on's data.

| Command | What it does |
|---|---|
| `/gam help` | shows this help |
| `/gam open` | opens the Grimoire Addon Manager window |
| `/gam version` | version, language and number of entries |
| `/gam log` | latest log messages (log clear to empty it) |
| `/gam language` | interface language (auto, frFR, enUS) |
| `/gam commands` | list of commands (commands add name / commands remove name) |
| `/gam theme` | window theme (auto, horde, alliance, neutral) |
| `/gam size` | starting size of the window (large, medium, compact) |
| `/gam font` | window font (game, gothic, cinzel) |
| `/gam mini` | switches between the full and the mini version |
| `/gam sheet` | tooltip and sheet parts (sheet tooltip off, sheet note on…) |
| `/gam options` | opens the options (options game: the Esc menu page) |
| `/gam search` | searches the add-ons (search fishing, search /way, search #pvp) |
| `/gam sort` | list sort (name, category, state, memory, usefulness; reverse) |
| `/gam tag` | tags of an add-on (tag Name pvp, to test) |
| `/gam favorite` | favorites (favorite Name to add or remove; no name: the list) |
| `/gam remove` | "to remove" list (remove Name to add or take off) |
| `/gam nosheet` | list of add-ons without a sheet |
| `/gam seen` | marks new and updated add-ons as seen |
| `/gam errors` | opens the Lua error window (errors clear to empty it) |
| `/gam memory` | add-on memory, biggest first |
| `/gam cpu` | CPU measuring mode (cpu on, cpu off, cpu reset) |
| `/gam profiles` | Opens the profiles window. |
| `/gam profile` | Applies a profile: profile <name>, profile all <name>, profile new <name>... |
| `/gam lock` | Locks or unlocks an add-on (never turned off by a profile). |
| `/gam enable` | Turns an add-on on with its dependencies and modules: enable <add-on>. |
| `/gam disable` | Turns an add-on and its modules off: disable <add-on>. |
| `/gam only` | Turns everything off except this add-on, its dependencies and the locked ones: only <add-on>. |
| `/gam trial` | Turns an add-on on for one session only: trial <add-on> (no name: the list). |
| `/gam safe` | Safe mode: turns everything off except the named add-ons and the locked ones. |
| `/gam back` | End of safe mode: puts everything back as it was. |
| `/gam reload` | Saves the choices then reloads the interface. |
| `/gam outdated` | Load out-of-date add-ons: outdated on\|off (no word: toggle). |
| `/gam undo` | Undoes the last change made in the list. |
| `/gam summary` | One line: add-ons, profile, pending changes, errors. |
| `/gam cheatsheet` | opens the cheat sheet: every command, a click types it in the chat (cheatsheet <word> to search) |
| `/gam tour` | starts the guided tour of the window (5 bubbles) |
| `/gam diag` | checks the uncertain points of the game (functions, images, settings) and records the result |
| `/gam trace` | records where every part of the window is on each click (for debugging); type again to stop |
