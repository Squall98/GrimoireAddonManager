# ⌨️ Commandes

`/gam`, `/maa` et `/mesaddons` marchent pareil (modifiables dans les options). Les mots anglais marchent aussi : `/gam help` = `/gam aide`.

39 sous-commandes, générées depuis les données de l'add-on.

| Commande | Ce qu'elle fait |
|---|---|
| `/gam aide` | affiche cette aide |
| `/gam ouvrir` | ouvre la fenêtre de Grimoire Addon Manager |
| `/gam version` | version, langue et nombre de fiches |
| `/gam journal` | derniers messages du journal (journal effacer pour le vider) |
| `/gam langue` | langue de l'interface (auto, frFR, enUS) |
| `/gam commandes` | liste des commandes (commandes ajouter nom / commandes retirer nom) |
| `/gam theme` | thème de la fenêtre (auto, horde, alliance, neutre) |
| `/gam taille` | taille de départ de la fenêtre (grande, moyenne, compacte) |
| `/gam police` | police de la fenêtre (jeu, gothique, cinzel) |
| `/gam mini` | passe de la version complète à la version mini et inversement |
| `/gam fiche` | infobulle et parties de la fiche (fiche infobulle non, fiche note oui…) |
| `/gam options` | ouvre les options (options jeu : la page du menu Échap) |
| `/gam chercher` | cherche dans les add-ons (chercher pêche, chercher /way, chercher #pvp) |
| `/gam tri` | tri de la liste (nom, catégorie, état, mémoire, utilité ; inverser) |
| `/gam etiquette` | étiquettes d'un add-on (etiquette Nom pvp, à tester) |
| `/gam favori` | favoris (favori Nom pour en ajouter ou en retirer ; sans nom : la liste) |
| `/gam desinstaller` | liste « à désinstaller » (desinstaller Nom pour en ajouter ou en retirer) |
| `/gam sansfiche` | liste des add-ons sans fiche |
| `/gam vus` | marque les nouveautés et mises à jour comme vues |
| `/gam erreurs` | ouvre la fenêtre des erreurs Lua (erreurs effacer pour la vider) |
| `/gam memoire` | mémoire des add-ons, du plus gourmand au plus sobre |
| `/gam cpu` | mode mesure du processeur (cpu activer, cpu couper, cpu zero) |
| `/gam profils` | Ouvre la fenêtre des profils. |
| `/gam profil` | Applique un profil : profil <nom>, profil tous <nom>, profil nouveau <nom>... |
| `/gam verrou` | Verrouille ou déverrouille un add-on (jamais désactivé par un profil). |
| `/gam activer` | Allume un add-on avec ses dépendances et ses modules : activer <add-on>. |
| `/gam desactiver` | Éteint un add-on et ses modules : desactiver <add-on>. |
| `/gam seul` | Éteint tout sauf cet add-on, ses dépendances et les verrouillés : seul <add-on>. |
| `/gam essai` | Allume un add-on pour une session seulement : essai <add-on> (sans nom : la liste). |
| `/gam depannage` | Mode dépannage : tout éteindre sauf les add-ons cités et les verrouillés. |
| `/gam retour` | Fin du dépannage : remet tout comme avant. |
| `/gam recharger` | Enregistre les choix puis recharge l'interface. |
| `/gam perimes` | Charger les add-ons périmés : perimes on\|off (sans mot : bascule). |
| `/gam annuler` | Annule le dernier changement fait dans la liste. |
| `/gam resume` | Une ligne : add-ons, profil, changements en attente, erreurs. |
| `/gam antiseche` | ouvre l'antisèche : toutes les commandes, un clic les écrit dans le chat (antiseche <mot> pour chercher) |
| `/gam visite` | lance la visite guidée de la fenêtre (5 bulles) |
| `/gam diag` | vérifie les points incertains du jeu (fonctions, images, réglages) et note le résultat |
| `/gam trace` | enregistre la place de chaque morceau de la fenêtre à chaque clic (pour Claude) ; retaper pour arrêter |
